# ctdR #4232

Overall the package provides a good starting point for analysis of
chemical-gene interactions. It should focus on providing helper functions for
working with the Comparative Toxicogenomics Db. It should not try to
re-implement existing methods but rather help the user create the necessary
data objects to integrate with existing infrastructure.

## DESCRIPTION

* Looks good.

## NAMESPACE

* Consider using `import` method and a CTD class e.g., from `BiocIO`

## vignettes

* Combining enrichment methods `enrichment_CTD` is common and available in
  other Bioconductor packages, e.g., `EnrichmentBrowser`. Please use existing
  infrastructure or provide rationale for implementing your own.
* Create a helper function to retrieve data from the cache (in `make-expr`
  chunk).

## R

* `import_CTD` should handle both the file path and the URL for user
  convenience
* Consider using `BiocFileCache` instead of `rappdirs` in `import_CTD`
* Use `@inheritParams` for `pAdjustMethod` or provide more extensive
  documentation for possible inputs.
